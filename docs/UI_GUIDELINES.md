# WayToMoksha UI Guidelines

## Design Philosophy

The design should feel:

- Calm
- Spiritual
- Clean
- Trustworthy
- Premium but simple
- Easy for non-technical users

The website should not feel like a generic business template.

Content should drive the design.

## Visual Direction

Use the WayToMoksha logo as the visual anchor.

Suggested color palette:

- White background
- Teal / turquoise for primary actions
- Saffron orange for spiritual warmth
- Navy blue for trust and depth
- Soft yellow/gold for highlights
- Light neutral gray for cards and sections

## Layout

Use spacious layouts.

Prefer:

- Large hero sections
- Clean cards
- Strong section headers
- Clear call-to-action buttons
- Mobile-first responsive design

Avoid:

- Crowded navigation
- Too many colors
- Dense paragraphs
- Template-style portfolio sections
- Irrelevant stock business sections

## Navigation

Main navigation:

- Home
- About
- Daily Sessions
- Retreats
- Volunteer
- Donate
- Contact

Donation should be visible and easy to access.

Retreat registration should have multiple entry points:

- Home page retreat card
- Retreats page
- Individual retreat detail page
- Direct shareable URL

## Home Page UX

The home page should quickly answer:

1. What is WayToMoksha?
2. What can I do here?
3. How do I join daily sessions?
4. Are there upcoming retreats?
5. How can I volunteer?
6. How can I donate?

Suggested home sections:

- Hero
- Mission summary
- Guided journey preview
- Daily sessions preview
- Upcoming retreat preview
- Donation preview
- Volunteer preview
- Footer

## About Page UX

The About page should include:

- Organization story
- Mission
- Vision
- Guided journey / getting started path

The guided journey should not be only an image. It should be HTML/content-based so it can later support calls to action like:

- Follow self-guided path
- Request guided mentorship
- Join daily sessions
- Start dream analysis

## Daily Sessions UX

Daily sessions should be easy to scan.

Use cards for:

- English meditation
- Telugu meditation
- 4P meditation
- Kids meditation
- Book readings
- Zoom/YouTube links

Do not bury session details inside long text.

## Retreats UX

Retreats should feel like a small portal.

Upcoming retreats:

- Date
- Location
- Short description
- Register button

Past retreats:

- Location
- Date
- Short summary
- Gallery preview

Retreat detail page should eventually support:

- Full description
- Venue
- Schedule
- Food/stay information
- Ticket options
- Optional donation
- Gallery
- Testimonials

## Donation UX

Donation page should clearly separate donations from fees.

Donation should be positioned as support for the mission.

Donation page should include:

- Main donation method
- Optional tiers
- Custom amount
- Donation purpose cards
- Tax-exempt note
- Admin review note if content is not final

During retreat registration, donation should appear only as an optional add-on.

## Volunteer UX

Volunteer page should make it easy to express interest.

The copy should make clear that registration is only the first step.

Flow:

1. User submits volunteer interest
2. Existing volunteer contacts them
3. Human onboarding happens
4. Role is assigned later in volunteer system

## Accessibility

Use:

- Good contrast
- Large readable text
- Clear button labels
- Mobile-friendly layouts
- Simple language

## AI Development Note

When Cursor builds UI, it should not create unrelated sections such as:

- Portfolio projects
- Generic client logos
- Random business statistics
- Fake team members
- Fake testimonials

Only use real or clearly marked placeholder content.
