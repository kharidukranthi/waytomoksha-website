# WayToMoksha Design Reference

## Purpose

This document captures visual inspiration for Checkpoint 5A and Checkpoint 5B.

The goal is not to copy another website. The goal is to extract a calm, polished, reusable design direction for WayToMoksha.

## Reference Website

Reference: Kalya Ventures LLC  
URL: https://www.kalyaventures.com/  
GitHub reference: https://github.com/KalyaVentures/KalyaVenturesWebsite

This site is used only for visual inspiration.

Do not copy:
- Content
- Business messaging
- Page structure
- Branding
- Company identity

## Design Inspiration to Borrow

Use these ideas:

- Cream / warm background
- Dark olive or deep green header
- Gold accent buttons
- Large serif headings
- Clean centered sections
- Soft card styling
- Generous spacing
- Calm, premium, trustworthy feel
- Simple navigation
- Warm footer
- Subtle patterned or textured hero sections

## WayToMoksha Identity

WayToMoksha should feel:

- Calm
- Spiritual
- Non-religious
- Non-profit
- Trustworthy
- Welcoming
- Accessible to users in the US and India
- Suitable for meditation, retreats, seva, donations, and volunteer work

## Suggested Initial Palette

Inspired by the Kalya Ventures visual direction:

- Deep olive / forest header
- Cream page background
- Warm gold accent
- Dark text
- Soft neutral cards
- Optional teal/turquoise accent if needed from existing WayToMoksha direction

Do not make the site look corporate.

Do not make the site look like a clone of Kalya Ventures.

## Checkpoint 5A Scope

Checkpoint 5A should define/refine:

- Theme tokens
- Color palette
- Typography
- Button styles
- Card styles
- Section spacing
- Background styles
- AdminReviewNote visual treatment
- Header/footer polish direction

Checkpoint 5A should not redesign every page.

## Checkpoint 5B Scope

Checkpoint 5B will apply the design system across:

- Home
- About
- Daily Sessions
- Retreats
- Retreat Detail
- Volunteer
- Donate
- Contact

## Design Principle

Build a WayToMoksha design system inspired by Kalya Ventures, but owned by WayToMoksha.
